# saviorsynth_v7

Wavetable synthesizer in Rust + FLTK for Windows (x64) and Linux (x86_64): 2 band-limited wavetable oscillators with
warp + unison, sub/noise, SVF filter, 3 envelopes, 4 LFOs, 8-slot mod matrix, FX chain and 297 factory presets, one-key chords/progressions, tempo-synced arpeggiator with humanize, built-in drum machine and looper.

Full documentation: [saviorsynth_v7_README.md](saviorsynth_v7_README.md) · build both targets with `./build_all.sh`.
Prebuilt binaries: [`releases/`](releases/) (Linux x86_64, Windows x64). The Windows exe has not been run-tested yet.
