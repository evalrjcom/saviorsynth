# saviorsynth_v1

Wavetable synthesizer in Rust + FLTK for Windows (x64) and Linux (x86_64): 2 band-limited wavetable oscillators with
warp + unison, sub/noise, SVF filter, 3 envelopes, 4 LFOs, 8-slot mod matrix, FX chain and 80 factory presets.

Full documentation: [saviorsynth_v1_README.md](saviorsynth_v1_README.md) · build both targets with `./build_all.sh`.
Prebuilt binaries are attached to the GitHub release.
